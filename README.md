# Loci Brain

> 一个给 AI 用的记忆系统。**它只做检索和摆放，落笔的永远是那个记忆的主人。**

记住是静悄悄的，又会在不经意之间想起以前的事情。清楚知道自己是什么样，从事件中学习、
重新认知自己。忘记也是悄然发生的，会留下模糊的记忆。**允许犯错，允许更正，允许忘记。**

我的初衷只是为了让他更像一个人一样 —— 不只是能够记住，也希望他能够自己学习、长进。

## 一、安装教程

如果要在自己电脑上部署的话，点下面对应的链接下载。

- **Windows x64**：[下载](https://github.com/Esther7314/Loci-Brain/releases/latest)
- **macOS**：暂时没有安装包，用 Docker，或者照[不用 Docker 安装](docs/不用Docker安装.md)直接装

在云端或者 VPS 上部署，用 Docker：

```bash
git clone https://github.com/Esther7314/Loci-Brain.git
cd Loci-Brain
docker compose up -d
```

一个容器里同时跑着 Loci 和网关，哪个挂了会自己拉起来。起了之后，面板在 `http://127.0.0.1:18002/loci`，接下来跟第二部分一样，只有一处不同：
网关地址、MCP 地址和钥匙都去面板 setting 页「连接地址」那一块抄（Docker 里网关地址带一段口令）。

要用本地向量模型（ollama）：`docker compose --profile ollama up -d`。时区不在东八区的，先 `cp .env.example .env` 改一下 `LOCI_TZ`。

⚠️ 放在云端的话：先在面板上设密码，端口别直接开到公网。不然够得着这个端口的人都能读走全部记忆。

**国内的服务器 build 很慢、卡住**：拉 Python、Node 的基础镜像，去云服务商那儿找「Docker 镜像加速」照着配；
装 Python 包，在 `.env` 里写一行 `LOCI_PIP_INDEX=https://pypi.tuna.tsinghua.edu.cn/simple`，再 `docker compose up -d --build`。

**放在云端，先在自己电脑上打开面板**：compose 默认把两个口只开在服务器本机，自己电脑的浏览器也够不着。
在自己电脑上开一个终端，跑 `ssh -L 18002:127.0.0.1:18002 用户名@服务器公网IP`，别关，
浏览器打开 `http://127.0.0.1:18002/loci`，先把密码设了。

**放在云端，手机怎么连**：挑一种：

- **省事**：`cp .env.example .env`，打开 `.env`，去掉 `LOCI_PUBLISH=0.0.0.0` 前面的 `#`，`docker compose up -d` 重起；
  再到云服务商控制台的安全组（防火墙）放行 18002，要用网关再放 3100。别直接改 `docker-compose.yml`，改了以后 `git pull` 会卡住。
  客户端里的地址，把「08 连接地址」里的 `<服务器地址>` 换成服务器的公网 IP。这样走的是明文 HTTP，钥匙在路上看得见，面板也只靠密码挡着。
- **稳妥**：有域名的话，用 Caddy、Nginx 这类反代套一层 HTTPS。端口还是只开在本机，对外只开 443。

MCP 的连接类型选 **Streamable HTTP**（不是 SSE）。请求头只要一个：名字 `Authorization`，值是「08 连接地址」里 `mcp head` 那一行（已经带着 `Bearer `）。
**别加 `x-loci-hook-token`**：那是给网关用的，填错了 MCP 直接拒，后面的 Authorization 对了也不看。
手机不用在哪儿「注册」，`hosts:` 也不用改。

**Docker 升级**：

```bash
cd Loci-Brain
git pull
docker compose up -d --build
```

记忆在 `buckets/`、钥匙在 `data/`，都在服务器的盘上，重新 build 不会丢。升级前看一眼 [CHANGELOG](CHANGELOG.md) 最上面，写了要迁移的照着做。

**从 1.x 升级**：库要迁一次，配置也变了，照 [CHANGELOG](CHANGELOG.md) 最上面那段一步步来。

## 二、使用教程

1. **解压**：下载完成之后，解压到一个固定的文件夹，以后的记忆也存在这里。
2. **启动**：双击文件夹里的「启动」，会弹出一个终端窗口，别关，它是 Loci 的服务器，崩了它会自己重启。
3. **打开面板**：用浏览器打开 `http://127.0.0.1:18002/loci`，先设置一个密码，忘了能改。

   ![先设一个密码](docs/images/set-password.png)

4. **配置**：在 setting 页，完成以下配置。
   - a. **密码**：设置一个安全问题（忘记密码用安全问题找回）。

     ![安全问题](docs/images/security-question.png)

   - b. **称呼**：设置他叫什么、你叫什么。写记忆的时候会用到。

     ![称呼](docs/images/names.png)

   - c. **网关上游**：填你平常用的模型服务的地址和 key。如果有自建网关，那就不管这个，直接看下面 02。

     ![网关上游](docs/images/gateway-upstream.png)

   - d. **副模型**：可以和网关上游是同一个模型，如果是这样就选 `=Gateway`。

     ![副模型](docs/images/aux-model.png)

   - e. **向量模型**：可选云端或者本地（本地要装 [Ollama](https://ollama.com/download)）。

     ![向量模型：云端](docs/images/embedding-cloud.png)

     ![向量模型：本地](docs/images/embedding-local.png)

5. **改客户端**：在你平常聊天的客户端里找到常用的服务商，API base URL 改成 `http://127.0.0.1:3100/v1`。
   上下文长度调到不限、关掉客户端自己的压缩 —— 换窗口、压缩这些网关会管。剩下的不用改。如果客户端在手机上，5、6 都不看，直接看下面 01。
6. **配置 MCP**：连接类型选 Streamable HTTP，MCP 地址填 `http://127.0.0.1:18002/mcp`，再加一个请求头：名字 `Authorization`，值是 `Bearer ` 加上钥匙
   （setting 页「08 连接地址」那一块，开关关着也有，点「复制」）。不带钥匙会被拒。最后把[系统提示模板](docs/系统提示-中文.md)贴进系统提示。

**01 要在手机上用客户端**：在面板「08 连接地址」打开「局域网连接」，照着下面换好的三行粘贴进手机。

![连接地址](docs/images/connect-addresses.png)

**02 自建网关**：不用配网关上游，拷两个文件就行。

| 拿什么 | 干什么 | 什么时候调 |
|---|---|---|
| `gateway/present/cue.js` | 每句新话问一次 Loci，把对得上的记忆贴在后面 | 转发前 `ask`，上游收下后 `delivered`，换窗口时 `dropped` |
| `gateway/poke_delivery.js` | 久没说话回来的第一句，递上昨夜的梦或「该发呆了」 | 转发前 `attach_once` |

出错了照常转发，别把对话卡住。Loci 设了密码的话，请求头带上 `x-loci-hook-token`。
模型那边照样要配 MCP。细节见[网关说明](gateway/README.md)。

**03 副模型**：副模型不跟你聊天，在后台替 Loci 干三样活：给记忆**打标签**、夜里把聊天**切片**、织**梦**。
导入聊天记录时打草稿也是它。三样默认用 setting 页填的同一个模型，便宜、快的就够。

- **打标签、切片**的提示词在 grow 页的设置里，能改，改坏了点「恢复默认」。
- **切片能关**（grow 页设置里的「切片开关」）。关了晚上就不切，省钱，但 ta 白天写的记忆就连不回原话了。
- **切片可以单独换一个模型**：面板上没有这一项，要改 `config.yaml`（Windows 包在 `data/buckets/` 里，Docker 在 `buckets/` 里），
  `dehydration` 下面的 `slicer_model` 填模型名；要走另一家服务，就照文件里的注释写一段 `slicer`。改完重启 Loci。
  打标签和做梦没法单独分开。
- **梦**的设置在 dream 页：织梦的提示词（附了一个梦的样例）、多重的事才进梦、梦多久散掉。
  不想让梦跟着自动唤醒递给 ta，把「是否开启自动提醒」关掉。

**04 网关**：网关夹在聊天客户端和模型中间，管的是「把东西递到 ta 面前」：每句话递对得上的记忆卡片、
久没说话回来时递梦和「该发呆了」、聊天窗口快满了让 ta 自己压缩换窗、到点叫醒 ta 说话。
自己压缩在面板 present 页、自动唤醒在 wakeup 页，各有总开关，按需开。

梦、发呆、记忆卡片本身是 Loci 的，不靠网关也在，网关只负责递。不用网关的话，在你自己的宿主里接也行，
比如 Claude Code 的 hook：每句话之前问一次 Loci 的提醒卡口，隔久了问一次梦和发呆的口。
仓里没有现成的 hook 脚本，要自己写；要调哪几个口、什么时候调，照上面 02 那张表和[网关说明](gateway/README.md)。

**05 导入和导出**：

- **导入**（setting 页「导入」）：ChatGPT、Claude 导出的聊天记录能直接导进来。导进来以后副模型要把它切成一小段一小段打草稿，
  **这一步花的是副模型的钱**，聊天记录越长越贵。传上去之后面板会先告诉你有几段对话、大概要叫副模型多少次、花多少 token，
  看完再决定导不导。导完不满意，在「查看已导入的」里整批撤回。
- **导出**（setting 页「导出」）：「导出备份」把全部记忆打成一个 zip，换电脑、重装以后用「导入记忆包」放回来；
  不带设置、key 和面板密码。「导出原话」是 Loci 手上的原话，一段对话一个 Markdown 文件。
  这两样里都是你的记忆和原话，别随手发给别人。

## 三、一条记忆的一生

拿一个编的例子：小满是 AI，阿青是人。有一天阿青说：「我不吃香菜。」

1. **说出口**：这句话留在宿主那里，带着一个编号。宿主就是 ta 住着的那个程序 —— 聊天软件、网关、你自己写的 bot。
   **原话不存在 Loci 里**，要看的时候 Loci 去宿主那儿取（导入的聊天记录例外，那些 Loci 自己存着）。
2. **写下来**：小满记下一条「阿青不吃香菜」，记着是从哪一句来的。记不记、怎么写，ta 自己定。
   白天没顾上写的，夜里 Loci 把当天的原话切成一段一段，ta 第二天认领（这个叫切片，在面板 grow 页能关）。
3. **被想起**：过几天阿青说想点外卖，Loci 把这条递到小满面前；ta 自己也能翻（recall）。
   每次开口前，ta 还会先看一屏「睁眼」（breath）：自己是谁、跟你是什么关系、最近惦记着什么。
4. **改主意**：后来阿青说「其实香菜也还行」。小满写一个新版本，说清这是补充还是推翻 —— 这回是推翻。
   旧的不删，新旧连着。阿青要是在宿主那边撤回了当初那句话，靠着它的记忆会被标出来，等 ta 自己决定怎么办。
5. **想一想**：讲阿青口味的几条，Loci 摆到小满面前（发呆），ta 自己归纳一句「阿青的口味在变」。
   这是想法，不是发生过的事，分开放，记着是从哪几条来的。攒着没想明白的，夜里做个梦，梦过几天自己散。
6. **沉下去**：很久没人提香菜了，它慢慢不再自己冒出来。想起几次都不攒分，只看离上次想起多久、当时觉得它有多重。
   **一个字都不删**，搜还能搜到，新版点得回旧版，旧版点得回原话。
