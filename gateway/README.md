# mini gateway · 把记忆递到眼前的那一层

> 术语跟 [技术实现](../docs/技术实现.md) 对齐。

---

## 一、是什么

Loci 的核心**不主动说话** —— MCP 是被动协议，工具没被调用就没有它的份。
核心只回答「现在该不该提醒」，**怎么把提醒递到眼前**在这一层。

它做两件事：

- **记忆库半自动化管理**的送达 —— 发呆（`muse`）和做梦攒够了，把结果递进对话
- **辅助回忆** —— 这句话像是在翻旧账，就去查一次，报「有几条相关」

形态是一个 OpenAI 兼容的转发层：调 Loci 的普通 REST 口
（`GET /api/loci/poke`、`POST /api/loci/dream/wake`），**不碰 MCP 工具面**；
API key 原样转发，不存不看。

## 二、有哪些 · 分别需不需要网关

### 必选的三样

| | 干什么 | 没有网关行不行 |
|---|---|---|
| **发呆**<br>`戳戳送达.js` | 攒了几团没整理的认知 → 递一句「该发呆了」 | **行。** `muse()` 是 MCP 工具，AI 自己伸手就能调，网关只是替它记得 |
| **做梦**<br>`戳戳送达.js` | 昨夜织的那个梦，递全文 | **不行。** 梦要能**拿走**（30 分钟降级、60 分钟删掉），而 hook 注入只增不减 —— 一个掉不下去的梦第二天还躺在上下文里，那就不是梦了 |
| **强弱提醒**<br>`自动贴.js` | 「〔记忆提醒〕和这句有关：事件 3 条 · 认知 1 条」 | **行。** 每轮跑一次 `recall`、把一行塞进去，hook 能做。网关的好处是插得进**真尾巴** |

### 可选的一样

| | 干什么 | 状态 |
|---|---|---|
| **收窗压缩** | 一天快结束时提醒写入、把当天压成几句、第二天带着它开窗 | **不给代码**，只给思路（第四节） |

## 三、必选项怎么配置

### ① 你已经有自己的网关 → 只拿两个模块

`戳戳送达.js` 和 `自动贴.js`，都**零依赖**（只用 `fs` / `path` / 全局 `fetch`）、
**零 import 这个项目**。拷走，在转发逻辑里加两句：

```js
const 桥 = require("./戳戳送达.js");

// 转发之前调一次。它会**就地**改 messages（插一条 system），也可能什么都不做。
await 桥.贴一次({
  messages: body.messages,              // 会被就地修改
  requestId: "随便什么能对上日志的字符串",
  地址: "http://127.0.0.1:18002/mcp",    // Loci 在哪（/mcp 结尾，它自己会转成 REST 根）
  闲时阈值分钟: 210,
});
```

```js
const 自动贴 = require("./自动贴.js");

// 强弱提醒：**最后一步**。它自己不碰 messages，只把 patch 算出来还给你——
// 位置要离模型开口最近，得等请求体都组完了再推进去。
const 提醒 = await 自动贴.算相关记忆提醒({ messages: body.messages, requestId, 地址, 最低分: 50 });
if (提醒 && 提醒.patch) 自动贴.贴到真尾巴(body.messages, 提醒.patch);
```

**两处都会抛异常 —— 你要接住，然后照常转发。** 宁可这次没插上，也不能让人的对话卡住。

📌 **函数名有英文别名**，指的是同一个函数，挑顺手的写：

```js
桥.paste({ ... })                       // = 贴一次
自动贴.computeReminder({ ... })          // = 算相关记忆提醒
自动贴.appendToTail(messages, patch)     // = 贴到真尾巴
```

文件内部是中文，改内部之前先读一遍注释——那些注释写着每个判断是怎么来的。

**两个位置不一样，是故意的：**

- **强弱提醒贴真尾巴** —— 每轮内容都不同，放前缀等于每轮都把 prompt 缓存打穿
- **发呆/做梦贴稳定前缀区** —— 闲够 3.5 小时才出现一次，那时候缓存本来就过期了；
  插进去之后它就是新前缀的一部分，后面每轮都能复用

### ② 你没有网关 → 用这个外壳

```bash
LOCI_UPSTREAM=https://api.deepseek.com/v1 node gateway/server.js
```

客户端的 `base_url` 指到 `http://127.0.0.1:3100/v1`。

| 环境变量 | 默认 | 干什么 |
|---|---|---|
| `LOCI_UPSTREAM` | 无（必填） | 真正的模型在哪，OpenAI 兼容地址 |
| `PORT` | `3100` | 网关自己听哪个端口 |
| `LOCI_MCP` | `http://127.0.0.1:18002/mcp` | Loci 在哪 |
| `POKE_IDLE_MINUTES` | `210` | 闲时闸，见下 |
| `RELEVANCE_STRONG_WORDS` | 中文默认表 | 强档词，逗号分隔。**不用中文的话必须换** |
| `RELEVANCE_MIN_SCORE` | `50` | 多少分以上才算相关 |
| `RELEVANCE_TIMEOUT_MS` | `12000` | 等 `recall` 多久。**库越大要给越多** |
| `RELEVANCE_WEAK` | 关 | `1` 打开弱档 |
| `LOCI_GATEWAY_DATA` | `gateway/data` | 状态和日志落哪儿 |

### 闲时闸

发呆和做梦**不是每个窗口开头都戳**，是**人长时间没说话之后的第一句**才戳（默认 210 分钟）。
它挡的是插嘴：在连着说话的空档里递一句「昨夜织了个梦」，那不是提醒，是打断。

### 什么时候才去查一次记忆（强档 / 弱档）

**不是每句话都去查** —— 查一次要几秒，而且大部分话根本不需要。
所以先在本地判断这句话值不值得查，两道闸：

| | 判据 | 例子 | 默认 |
|---|---|---|---|
| **强档** | 出现了明说要翻旧账的词 | 「**上次**你说的那个方案」 | 开 |
| **弱档** | 没有那种词，但这句话有实质内容（不是应声话） | 「明天去医院复查」 | **关** |
| 两档都不过 | 应声话、问候语 | 「嗯」「好的」「在吗」 | 不查 |

命中了才去 Loci 跑一次 `recall`，过分数线的条数拼成那一行贴回去；
一条都没过就一个字都不说。

**强档词表可以整表换**（默认是中文）：

```bash
RELEVANCE_STRONG_WORDS="remember,last time,earlier,you said"
```

不分大小写，句首大写的 `Remember when…` 照样认。
**不换的话，不说中文的人一次都不会触发** —— 而且不会收到任何提示。

**弱档为什么默认关**：它太宽，日常说话几乎每句都过，于是每一轮都会跳一行
「有 N 条相关记忆」——**每轮都响的提醒等于没有提醒**。
（不是因为慢：一次 `recall` 在 1300 条的库上约 3 秒，开着也扛得住。）
你更怕漏掉、不怕吵，就 `RELEVANCE_WEAK=1` 打开。

⚠️ **超时给太少 = 这功能悄悄不工作。**

它原来写死 5 秒，而当时一次带 `query` 的 `recall` 要 5~7 秒 ——
于是**它每次都超时中止、命中数恒为 0，从上线到发现一次都没成功过**。
而失败只进日志、聊天照常，**界面上永远是正常的**。

现在默认 12 秒（`RELEVANCE_TIMEOUT_MS`）。三个数你得知道：

| | 1300 条的库实测 |
|---|---|
| 平时（索引热着） | **约 3 秒** |
| **Loci 刚重启后的第一次** | **15 秒上下** —— 向量和 BM25 索引是冷的 |
| 库更大 | 更慢，**跟条数走** |

📌 所以 **Loci 重启之后的第一次相关检查大概率还是会超时**，之后就正常了。
它失败得很安静，别以为是坏了。

**怎么确认它在工作**：看日志里 `relevance_reminder_observed` 那条的
`injected` 和 `error` —— **别看聊天界面，界面上永远是正常的。**

## 四、可选项：收窗压缩

**这件事跟网关没关系** —— 它无非是「系统在某个时刻说一句话」，hook、系统提示、
客户端自己弹一句都能做。所以这儿只说要说什么：

**当天**：按窗口余量提醒几次「该收了」（不是倒计时，是让 AI 把刀口挪到一段话说完的地方）
→ 收窗时提醒把该存的存进 Loci → 用几句话概括这一天，**写成情景记忆**：
第一人称，把当时的感受一起留下，不是会议纪要。

**第二天**：那几句 + 最近 10~15 个来回。

## 三条它自己守的边界

- 🔴 **失败不挡聊天。** Loci 没起、超时、返回不是 JSON —— 全部照常转发，只记一行日志。
- 🔴 **只报数量，不报内容。** 给摘要 = 系统替他想起来了，他会顺着摘要往下说；
  给数量 = 拍他一下，**要不要真去看是他的判断**。（梦是例外：梦是交付，给全文。）
- 🔴 **每轮现算，不累积。** 0 条就一个字都不说，连标记行都不出现。
